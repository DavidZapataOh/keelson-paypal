# @keelson/interop

Exports a Keelson Alibi, with the mandate it was bought under, to the agentic-commerce standards, and verifies those exports offline:

| Format | Standard                                                                         | Pinned at                                    | Checked with                                                  |
| ------ | -------------------------------------------------------------------------------- | -------------------------------------------- | ------------------------------------------------------------- |
| `ap2`  | Agent Payments Protocol v0.2                                                     | `google-agentic-commerce/AP2@e1ea56db`       | AP2's Python SDK; `goodmeta/ap2-conformance@41dff653` vectors |
| `vi`   | Mastercard Verifiable Intent v0.1                                                | `agent-intent/verifiable-intent@356c2963`    | `verify_chain` and `check_constraints`                        |
| `ucp`  | Universal Commerce Protocol 2026-08-25                                           | `Universal-Commerce-Protocol/ucp@87dd4b1f`   | `ucp-schema` 1.4.1                                            |
| `acp`  | Agentic Commerce Protocol 2026-04-17                                             | `agentic-commerce-protocol@7fdd78df`         | the spec's JSON Schema                                        |
| `tap`  | Visa Trusted Agent Protocol, Mastercard Agent Pay, Web Bot Auth                  | RFC 9421; `cloudflare/web-bot-auth@01c0d10a` | `web-bot-auth` 0.2.0, RFC 9421 and must-reject vectors        |
| `visa` | Visa Core Rules §4.1.23 and Compelling Evidence 3.0 (edition of 24 October 2026) | —                                            | `schemas/visa-evidence-pack.schema.json`; veraPDF (PDF/A-3b)  |

Every export embeds the Alibi it was made from. `verifyExport` checks the standard's own signatures and bindings, verifies the embedded Alibi (the two enclaves' countersignature, their attestations and the log proof) and requires every exported amount, currency, merchant, payee, line and nonce to equal the countersigned one. The issuer slot of each standard is signed with Keelson's export key, which is not an enclave key: a forgery signed with that key still fails on the countersigned facts.

`vendor/` holds the upstream schemas and vectors byte for byte, each with its license; `vendor/PINS.json` records their commits and SHA-256. Refresh them with `pnpm vendor`.
